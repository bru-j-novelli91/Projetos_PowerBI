 # 🚚 Dashboard Logístico

## 📋 Sobre o Projeto

O Dashboard Logístico foi desenvolvido para monitorar e analisar indicadores essenciais da operação logística, fornecendo uma visão clara e estratégica dos processos de transporte, distribuição e desempenho operacional.

## ✨ Funcionalidades

- 📦 Monitoramento de entregas realizadas

- 🚛 Controle de status de transporte
  
- ⏱️ Análise de tempo médio de entrega

- 📈 Acompanhamento de indicadores de desempenho (KPIs)

- 📍 Visualização de rotas e distribuição geográfica
18
- 📊 Gráficos interativos para análise logística
19
- 🔍 Filtros dinâmicos por período, região e transportadora

## 🛠️ Tecnologias Utilizadas

- Power BI
- Excel
